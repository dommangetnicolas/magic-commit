# Screenshots

Drop these PNGs here; the landing page picks them up automatically and shows a placeholder for any that are missing.

| File | What to capture |
| --- | --- |
| `panel.png` | The whole panel open under the menu bar, with several projects in different states. Also used as the social preview image. |
| `commit.png` | A project row with uncommitted changes and the Commit button. |
| `wip.png` | A project row with a few WIP commits. |
| `batch-oco.png` | The Batch oco button on a project with several WIP commits. |

Capture a window with its shadow: press ⌘⇧4, then Space, then click the panel.
The hero frame is 4:5 and the feature frames are 16:10; images are cropped from the top to fit.
